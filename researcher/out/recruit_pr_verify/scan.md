# 走査 — recruit_pr_verify（仮説の検証：中堅製造業向け採用広報）

更新：2026-11-05（Claude）。数字はすべて scan_auto.md（GitHub の scan.py）からの転記。こちらで計算はしていない。

## 先に直したこと（事後報告）
- 金額の欄（「採用にいくら払うか」「採用広報・採用サイトの単価」）に、統計の総額・企業の売上・資本金・制作単価が混ざっている（例：経営課題の順位の品目で 1.9〜100000 万円、造船クラスターで 0.3〜4.212e+07 万円）。この幅は**同じものを測っていない**ので、中央値も向きも採らない。
- scan.py に文脈分け（装置価格・市場規模・売上・統計の総額・単価）、見出し・抜粋の除外、サイト共通文の除外を入れた（METHOD.md 4-5）。次の GitHub の実行で作り直される。

## A1の判断に効く点（3つまで）
1. 瀬戸内・技術職の有効求人倍率は一次で1倍を超えており、「採用に困っている」は【一次で確認】の範囲で言える。
2. 「営業より採用に困っているか」は、今の材料では**言えない**（設問の違う調査が混ざっている）。仮説の核なので、同じ設問の調査（中小企業白書・商工会議所・日銀短観の雇用人員判断DIの規模別）で取り直す。
3. 採用広報の単価は、記事と料金表の混在で使えない。各社の公式料金表を一次として取り直す。

## 分かっていないこと
- 同じ設問で「人材確保」と「販路開拓・受注」を並べた一次調査（年ごと）。
- 日銀短観の製造業・規模別の雇用人員判断DIの10年推移（区分が混入）。
- 瀬戸内5県の製造業の規模別社数（経済センサスの同じ表で）。
- 採用広報・採用サイト制作の公式料金表。
