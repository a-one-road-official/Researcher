# 走査 — am_ceiling（金属AM受託の頭打ち金額）

更新：2026-11-05（Claude）。数字はすべて scan_auto.md（GitHub の scan.py が出したもの）からの転記。こちらで計算はしていない。

## 先に直したこと（事後報告）
- scan_auto.md の「1件の単価」「最大案件・上限」の万円の欄に、**関連記事の題名**（「3Dプリンターの値段はいくら？1万円〜1億円まで価格帯別に徹底解説」）の 1万円・1億円が何度も入っていた。2025年の 2.5e+07 万円、2026年の 5000.5 万円という中央値はこの混入と市場規模の数字によるもので、**単価としては使えない**。
- **装置の価格**（「産業用の金属3Dプリンターは3,000万円〜数億円程度」nikon）が受託単価の欄に入っていた。
- 対策として scan.py に「見出し・題名・抜粋を数字にしない」「装置価格／市場規模／売上／単価を文脈で分ける」「調査会社は1件に束ねる」「予測年を向きの計算から外す」を入れた（METHOD.md 4-5）。次の GitHub の実行で scan_auto.md が作り直される。

## 【事実】と【推定】
- 【事実】使える単価の引用は国内の「1パーツ5,000円〜10,000円程度」（記事）1件だけ。
- 【推定】なし。混入を外す前の中央値・向き（上昇／下降）はすべて採らない。

## A1の判断に効く点（3つまで）
1. 金属AM受託の「1件・1社年間の上限」は、今の材料では**数字で言えない**。頭打ちの議論は保留。
2. 量産・防衛・航空の大型の数字は、ほぼ市場規模か予測値で、1社が取れる金額ではない。
3. 一次（各社の料金表・防衛省の契約実績・海外上場受託会社の決算）を当て直せば埋まる。

## 分かっていないこと
- 国内受託各社の公開料金表（公式）、1社あたり年間の受託売上（官報・決算公告）、海外受託会社（上場）の決算の受託売上、防衛省の契約実績の品目・金額。
- 調査は止まっている（control.yaml で run: false）。穴埋めの品目を inputs/am_ceiling.csv に足し、run: true にした。
