# am_users リスト選定条件（2026-11-11、Tamuraと1つずつ擦り合わせ済み）

- 母集団：Drive の ipros_all（45,108社）のみ。他の種（表彰リスト等）は足さない。ウェブ全体の検索からも拾わない。
- 地域：全国（本社所在地で切らない）。
- 財務条件：なし（売上・粗利・資本金で切らない）。
- AM使用の有無：切らない。使用している会社も、していない会社も当たる。保有は外部から特定できない（公開していない会社が多数）ので、保有・使用を判定軸にしない。
- 選定の軸：取扱製品でソートする。設備ではない。
  - 一点物・少量多品種の製品を作っている会社が望ましい（トラクションがある）。
  - 製品カテゴリーと取扱材料が AM と合う会社を拾う。例：医療向けチタン、航空機向け部品、自動車向けブラケット。
  - 判断の参考：Drive「A1 金属AM 山の地図」（ランドスケープ）。AM業界・学会・製品ケーススタディを統合すると、どの製品にどの素材が使われ、どの規模の開発がどのレイヤーで起きるかが分かる — それを製品→素材→AM適合の地図として使う。
- 会社の種類：ものづくり企業（製作所・メーカー）を中心に、デザイン会社・建築事務所も含める。
- 素材：全部。金属、複合材、CFRP、セラミック、スーパーエンプラ、紙など。
- 除外：なし。装置メーカー・販売店・材料メーカー（売る側）も、大学・公設試も除外しない。カテゴリで切らない。
- 出力：公式URL、メールアドレスの2列だけ。メールが公開されていない会社は、メールの列に問い合わせフォームのURLを入れる。
- 品質基準（2026-11-11 追加分）：対象0件という結果は認めない／実在する会社に「URLが見つかりません」を最終判定にしない／数を水増ししない。
- レベル感の前提：顧客になり得るのはシモダフランジ、ケイブラッシュ商会のクラス（専門・単品の中小製作所）。ipros_all を母集団にすることでこのレベルに自然に寄る。ウェブ検索ベースの採取は大手・有名機関に偏るため使わない。
- 実行場所：GitHub側（Researcher の仕組み）。このチャットでは作らない（2026-11-11 本人指示）。
