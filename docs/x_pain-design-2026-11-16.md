- H1 品質書類：受託造形・加工の現場の本人が、検査成績書・ミルシート・品質記録の手書き・転記・作成に、残業・ミス・監査・納期のいずれかを結びつけて書いた投稿。
- H2 部品の追跡：部品のロット・シリアル・刻印の紐付けが追えないことを、出荷・不良・監査・探す時間のいずれかと結びつけた本人の投稿。
- H3 治具：治具・冶具の設計・作図を毎回やる負担を、時間・残業・追いつかないのいずれかと結びつけた本人の投稿。

## 6. KJ法の素材形式

- 1投稿＝1カード：全文、URL、投稿日、投稿者の立場（候補でよい、確定と書かない）、痛みのキーワード（投稿者の言葉のまま抽出）。
- 機械は寄せない。寄せる（グルーピング）のは社長がやる。機械の仕事は、カードを作ることと、キーワードの出現数・傾向をカード単位で数えて併記することだけ。
- ベンダー公式・メディア・転載は「霧」として別枠に数える。毎回、分母（読んだ件数／本人の声の件数／霧の件数）を出す（第四条）。

## 7. 上限（第三条：変更禁止）

- max_posts_per_run は現行値のまま変えない。X 開発者コンソールの使用額上限と GitHub Actions の上限設定を外さない。上限で止まる設定が前提。
